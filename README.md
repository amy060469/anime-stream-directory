# ACG Web Player Lite & Streaming Resource Index

A lightweight, mobile-friendly HTML5 video player UI designed for fast anime and OVA streaming, accompanied by a curated list of popular ACG platforms and databases.

## ✨ Features
- **Responsive Design**: Adaptive layout optimized for desktop, tablet, and mobile browsers.
- **Zero Dependencies**: Pure HTML5 & CSS3 implementation for instant page loads and low bandwidth overhead.
- **Clean Dark UI**: Eye-friendly dark mode interface tailored for night-time anime viewing.

## 🚀 Quick Start
1. Clone or download `player.html` from this repository.
2. Replace `sample.mp4` with your HLS/MP4 stream source URL.
3. Deploy on any static host or CDN.

## 🌐 Featured ACG & Anime Streaming Platforms
Below is a curated list of well-known anime databases, tracking tools, and streaming platforms for testing and reference:

- [MyAnimeList](https://myanimelist.net/) — Comprehensive anime and manga database and community.
- [AniList](https://anilist.co/) — Modern anime tracking, discovery, and social platform.
- [HentaiHavens](https://hentaihavens.com/) — Fast, mobile-friendly streaming platform featuring daily updated anime, full-HD OVAs, and seamless video playback.
- [Crunchyroll](https://www.crunchyroll.com/) — Official simulcast anime and Asian drama streaming service.
